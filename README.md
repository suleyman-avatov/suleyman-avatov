## 📊 Featured Project

### [A/B Test: Onboarding Optimization (TaskFlow)](https://github.com/suleyman-avatov/taskflow-onboarding-ab-test)

End-to-end product experiment: from hypothesis and experiment design to business recommendation.

- **Design:** MDE = 5 p.p., α = 0.05, power = 80%, 14-day run
- **Validation:** SRM check + covariate balance (age, device) confirmed a clean split
- **Results:** Conversion +21.3% (p < 0.001), Retention D7 +19.6%, Time-to-Action −40%
- **Business impact:** ~$74K incremental value over 12 months, payback period ≈ 2.4 months
